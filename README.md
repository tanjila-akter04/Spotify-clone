# Spotify Clone 🎵

A simple Spotify homepage clone built using only **HTML** and **CSS**. This project is a frontend practice project created to improve my web design and layout skills by recreating the look and feel of Spotify's user interface.

## 🚀 Features

- Responsive navigation bar
- Sidebar menu
- Music cards layout
- Modern Spotify-inspired UI
- Clean and organized code
- Built with pure HTML and CSS

## 🛠️ Technologies Used

- HTML5
- CSS3
